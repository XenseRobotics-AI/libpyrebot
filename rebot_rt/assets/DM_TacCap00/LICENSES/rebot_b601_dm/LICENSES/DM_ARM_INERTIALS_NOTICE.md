# DM arm nominal inertial parameters

Mass, center of mass and inertia for base_link and link1..5 are taken from
Seeed-Projects/reBotArm_control_py, urdf/DM/urdf/ReBot_Arm_DM.urdf.
Repository revision and source SHA-256 are recorded in sources.json.
These nominal parameters also match libpyrebot's DM arm model; they are
not measured identification results for this robot. The source checkout
does not contain a license file. REBOT_ISAACSIM_MIT covers the separately
sourced simulation geometry, not this parameter provenance.
